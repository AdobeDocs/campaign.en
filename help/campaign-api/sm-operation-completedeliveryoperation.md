# CompleteDeliveryOperation

Completes a delivery created in the context of a campaign.

```text
XML deliveryOut = CompleteDeliveryOperation ( XML deliveryIn, XML parameter )
```

## Parameters

**deliveryIn** Inbound delivery

**parameter** Configuration of the campaign context

## Return value(s)

**deliveryOut** Delivery updated

## Features

**Schema:** [nms:operation](s-nms-operation.md)

**Static:**

Yes
