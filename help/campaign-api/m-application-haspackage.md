# hasPackage

Tests if a package is installed.

```text
hasPackage (name)
```

## Parameters

**name** Full name of the package.

## Return value

True if the package is installed.

## Remarks

Example:

```javascript
var hasMRM = application.hasPackage("nms:mrm")
```
