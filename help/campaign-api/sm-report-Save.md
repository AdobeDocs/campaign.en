# Save

Saves a report already generated in the database.

```text
XML result = Save ( XML data, String reportName )
```

## Parameters

**data** Data used by the reports

**reportName** Internal name of the report

## Return value(s)

**result** Unique identifier and record date

## Features

**Schema:** [xtk:report](s-xtk-report.md)

**Static:**

Yes
