# RecipientSubscribe

Subscribe/unsubscribe selected recipients to a list of Information Services.

```text
XML confirmationIds = RecipientSubscribe ( XML recipientList, XML serviceList, Boolean subscribe, XML sendConfirmation )
```

## Parameters

**recipientList** Recipient list

**serviceList** List of services

**subscribe** Subscribe/Unsubscribe recipients

**sendConfirmation** Send a confirmation message

## Return value(s)

**confirmationIds** List of confirmation IDs

## Features

**Schema:** [nms:subscription](s-nms-subscription.md)

**Static:**

Yes
