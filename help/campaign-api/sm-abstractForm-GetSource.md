# GetSource

Source code of form management.

```text
[ String source, XML logs ] = GetSource ( String formId, String target, Boolean compiled, String version )
```

## Parameters

**formId** Form identifier.

**target** Document type to generate.

**compiled** Recover the complete version

**version** Document version to generate.

## Return value(s)

**source** Source code.

**logs** Generation logs.

## Features

**Schema:** [xtk:abstractForm](s-xtk-abstractForm.md)

**Static:**

Yes
