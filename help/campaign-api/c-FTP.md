# FTP (Class)

An FTP object enables you to perform a number of operations using the FTP protocol.

## Methods

| Method | Description |
| --- | --- |
| [FTP](m-FTP-FTP.md) | Creates a new object to execute FTP commands. |
| [dispose](m-FTP-dispose.md) | Frees the resources used by the object. |
| [list](m-FTP-list.md) | Returns the list of files on the server in a specified directory. |
| [download](m-FTP-download.md) | Downloads a file from the server to a local file or to memory. |
| [upload](m-FTP-upload.md) | Download a file from a local file to an FTP server. |
| [setFile](m-FTP-setFile.md) | Defines the transfer mode and the receiving file. |
