# CompleteURLParams

Complete the success URL

```text
String result = CompleteURLParams ( String formName, String xpathParams, XML recipient )
```

## Parameters

**formName** Form name

**xpathParams** Comma-separated list of XPaths to return

**recipient** Recipient data

## Return value(s)

**result** Return parameters for the URL

## Features

**Schema:** [nms:webForm](s-nms-webform.md)

**Static:**

Yes
