# CreateRequestByName

Create a new GDPR Request using namespace internal name

```text
Number id = CreateRequestByName ( String namespaceName, String reconciliationValue, Number type, Boolean confirmDeletePending )
```

## Parameters

**namespaceName** Namespace internal name

**reconciliationValue** Reconciliation value

**type** Reconciliation value

**confirmDeletePending** Request confirm before deleting data

## Return value(s)

**id** ID of newly created request

## Features

**Schema:** [nms:gdprRequest](s-nms-gdprrequest.md)

**Static:**

Yes
