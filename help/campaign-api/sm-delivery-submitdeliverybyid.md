# SubmitDeliveryById

Create and submit a delivery from a scenario (identified by it's internal name).

```text
Number deliveryId = SubmitDeliveryById ( Number scenarioId, XML content )
```

## Parameters

**scenarioId** Template identifier

**content** XML content to add to the template

## Return value(s)

**deliveryId** XML content to add to the template

## Features

**Schema:** [nms:delivery](s-nms-delivery.md)

**Static:**

Yes
