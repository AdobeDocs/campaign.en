# getValue

Returns the node value referenced by the given XPath.

```text
getValue (xpath)
```

## Parameters

**xpath** Path.

## Return value

Text value of node referenced.

## Remarks

The syntax for the XPath only accepts an XPath language subset. An exception is raised if the path is badly formed.
