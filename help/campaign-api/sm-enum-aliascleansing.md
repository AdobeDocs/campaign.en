# AliasCleansing

Update database using cleansed enumerations.

```text
AliasCleansing ( XML where, Date fromDate, Boolean refreshHit, Boolean resetHit )
```

## Parameters

**where** Enumerations filter.

**fromDate** Start date for survey responses.

**refreshHit** Hit update.

**resetHit** Hit update from the start.

## Return value(s)

None.

## Features

**Schema:** [xtk:enum](s-xtk-enum.md)

**Static:**

Yes
