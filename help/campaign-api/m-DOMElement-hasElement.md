# hasElement

Tests whether the element has a child element by verifying the given criteria.

```text
hasElement (tagName [, attrName ] [, attrValue ])
```

## Parameters

**tagName** Name of searched element.

**attrName** Name of an attribute that has to verify a given value.

**attrValue** Attribute value.

## Return value

true if the element has a child by verifying the given data, otherwise false.
