# MoveSelection

Move selection into a navigation tree folder

```text
MoveSelection ( String schemaId, String entityFolder, XML selectionList, String key )
```

## Parameters

**schemaId** Selection schema Id

**entityFolder** Id of the destination folder

**selectionList** Selection to move

**key** Node key

## Return value(s)

None.

## Features

**Schema:** [xtk:folder](s-xtk-folder.md)

**Static:**

Yes
