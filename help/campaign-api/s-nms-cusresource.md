# cusResource

Data mapping for replication

## Methods

| Method | Description |
| --- | --- |
| [CreateCusResource](sm-cusresource-createcusresource.md) | Automatically create custom resources with auto discovery for fields/index/link/key. |
| [CreateFDASchema](sm-cusresource-createfdaschema.md) | Automatically create schemas used by the FDA from ACS custom resources. |
| [GenerateCusResources](sm-cusresource-generatecusresources.md) | Push all custom resources in the ACS custom resources set. |

## Generic Methods

| Method | Description |
| --- | --- |
| [create](f-create.md) | Creates a new entity corresponding to a given schema. |
| [load](f-load.md) | Loads and returns an entity corresponding to a given schema and key. |
| [save](m-entity-save.md) | Saves an entity in the database. |
