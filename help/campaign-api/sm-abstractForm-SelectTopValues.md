# SelectTopValues

Recovers the top n values

```text
XML selectedValues = SelectTopValues ( String schema, String expr, Number classCount )
```

## Parameters

**schema** Root schema of analysis

**expr** Source expression

**classCount** Number of bins to generate

## Return value(s)

**selectedValues** List of values

## Features

**Schema:** [xtk:abstractForm](s-xtk-abstractForm.md)

**Static:**

Yes
