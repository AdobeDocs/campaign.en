# hasRight

Tests if the operator has a specific named right.

```text
hasRight (name)
```

## Parameters

**name** Right name.

## Return value

True if the operator has this right.

## Remarks

Example:

```javascript
      var hasAdminRight = application.operator.hasRight("admin")
```
