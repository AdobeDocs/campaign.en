# FillSteps

Automatically create cutoffs for an equal number of bins.

```text
XML samplingSteps = FillSteps ( String schema, String expr, Number classCount )
```

## Parameters

**schema** Root schema of analysis

**expr** Source expression

**classCount** Number of bins to generate

## Return value(s)

**samplingSteps** List of steps

## Features

**Schema:** [xtk:abstractForm](s-xtk-abstractForm.md)

**Static:**

Yes
