# SubmitSoapCall

Submits a job for an asynchronous processing

```text
String id = job.SubmitSoapCall ( XML soapCall ) const
```

## Parameters

**soapCall** Method to call for the entity

## Return value(s)

**id** Identifier of job just created

## Features

**Schema:** [xtk:job](s-xtk-job.md)

**Static:**

No

**Const:**

Yes

**Key only:**

No
