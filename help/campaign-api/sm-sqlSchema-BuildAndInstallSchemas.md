# BuildAndInstallSchemas

Generates the code of a schema from the physical structure of the table given in the parameters.

```text
BuildAndInstallSchemas ( String dataSource, String namespace, XML tableList )
```

## Parameters

**dataSource** ID of the data source

**namespace** Namespace

**tableList** List of selected tables

## Return value(s)

None.

## Features

**Schema:** [xtk:sqlSchema](s-xtk-sqlSchema.md)

**Static:**

Yes
