# GenerateVolumeLines

Generates availability lines for the current typology

```text
GenerateVolumeLines ( Number ruleId, ??? lineDuration, Number quantity, String scheduling, String subChannel )
```

## Parameters

**ruleId** Rule ID

**lineDuration** Availability time per line

**quantity** Quantity available

**scheduling** Generation parameters

**subChannel** Logical sub-channel ID

## Return value(s)

None.

## Features

**Schema:** [nms:typologyRule](s-nms-typologyRule.md)

**Static:**

Yes
