# DOMCharacterData (Class)

A node containing text only. It can be a text type node or a comment.

## Methods

| Method | Description |
| --- | --- |
| [substringData](m-DOMCharacterData-substringData.md) | Extract a part of the text. |
| [appendData](m-DOMCharacterData-appendData.md) | Add a character string to the text. |
| [insertData](m-DOMCharacterData-insertData.md) | Inserts a character string to the text at a specific position. |
| [deleteData](m-DOMCharacterData-deleteData.md) | Delete a part of the text. |
| [replaceData](m-DOMCharacterData-replaceData.md) | Remplace a part of the text. |

## Properties

| Property | Description |
| --- | --- |
| [data](p-DOMCharacterData-data.md) | Text value of the node. |
| [length](p-DOMCharacterData-length.md) | Number of charcaters in the node. |
