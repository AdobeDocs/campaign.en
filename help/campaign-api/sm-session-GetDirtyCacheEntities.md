# GetDirtyCacheEntities

Return dirty cached entities

```text
XML dirtyEntities = GetDirtyCacheEntities ( XML cacheEntities )
```

## Parameters

**cacheEntities** List of cached entities

## Return value(s)

**dirtyEntities** List of dirty entities

## Features

**Schema:** [xtk:session](s-xtk-session.md)

**Static:**

Yes
