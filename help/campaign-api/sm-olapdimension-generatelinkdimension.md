# GenerateLinkDimension

Generate a dimension based on a link.

```text
XML result = GenerateLinkDimension ( XML dimension, XML linklevels )
```

## Parameters

**dimension** Dimension to enter

**linklevels** Available levels

## Return value(s)

**result** Entered dimension

## Features

**Schema:** [xtk:olapDimension](s-xtk-olapdimension.md)

**Static:**

Yes
