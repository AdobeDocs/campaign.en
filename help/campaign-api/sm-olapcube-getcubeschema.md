# GetCubeSchema

Obtain the schema of a cube

```text
XML schema = GetCubeSchema ( Number cubeId, Boolean withDimensions )
```

## Parameters

**cubeId** Cube identifier

**withDimensions** Include dimensions

## Return value(s)

**schema** Schema

## Features

**Schema:** [xtk:olapCube](s-xtk-olapcube.md)

**Static:**

Yes
