# CountListExport

```text
Number result = CountListExport ( Number cubeId, XML cube, XML conditions, String path )
```

## Parameters

**cubeId** Cube identifier

**cube** Serialized XML describing the cube.

**conditions** List of selections

**path** Path to the elements to be exported

## Return value(s)

**result** Number of elements to be exported

## Features

**Schema:** [xtk:olapCube](s-xtk-olapCube.md)

**Static:**

Yes
