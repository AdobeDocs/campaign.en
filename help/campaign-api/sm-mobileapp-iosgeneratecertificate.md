# iOSGenerateCertificate

Encodes the provided iOS certificate in base64

```text
String return = iOSGenerateCertificate ( String fileName, String uuid )
```

## Parameters

**fileName** File name

**uuid** application UUID

## Return value(s)

**return** The base64 version of the certificate
