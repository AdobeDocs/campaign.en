# BuildSqlSchemaDiff

Generates a document describing differences between the actual database structure and its logical description.

```text
XML sqlSchemaDiff = BuildSqlSchemaDiff ( XML sqlDiffParam, XML package )
```

## Parameters

**sqlDiffParam** Extension Parameters

**package** Initial package

## Return value(s)

**sqlSchemaDiff** SqlSchemaDiff generated

## Features

**Schema:** [xtk:builder](s-xtk-builder.md)

**Static:**

Yes
