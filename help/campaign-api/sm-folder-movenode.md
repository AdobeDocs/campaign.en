# MoveNode

Move folder in the navigation tree

```text
MoveNode ( String key, String parentKey, Number order, String fullName )
```

## Parameters

**key** Node key

**parentKey** Parent key

**order** New node index

**fullName** Full name (not empty to change parent in the tree)

## Return value(s)

None.

## Features

**Schema:** [xtk:folder](s-xtk-folder.md)

**Static:**

Yes
