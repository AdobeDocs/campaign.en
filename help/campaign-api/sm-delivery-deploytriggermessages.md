# DeployTriggerMessages

Publish the selected transactional messages on the execution instances

```text
DeployTriggerMessages ( XML deliveries, Boolean localPublish )
```

## Parameters

**deliveries** Filter conditions for defining the transactional messages to deploy

**localPublish** Publish on the control instance only?

## Return value(s)

None.

## Features

**Schema:** [nms:delivery](s-nms-delivery.md)

**Static:**

Yes
