# HttpServletResponse (Class)

Represents the response of a servlet returned to a client.

There is only one instance of this class accessible by the `response` variable.

## Methods

| Method | Description |
| --- | --- |
| [setContentType](m-HttpServletResponse-setContentType.md) | Changes the document type of the response. |
| [sendRedirect](m-HttpServletResponse-sendRedirect.md) | Returns a temporary redirection to another URL. |
| [addCookie](m-HttpServletResponse-addCookie.md) | Adds a cookie to the response. |
| [addHeader](m-HttpServletResponse-addHeader.md) | Adds an additional HTTP header to the response. |
| [sendError](m-HttpServletResponse-sendError.md) | Returns an error response using the error code passed as a parameter. |

## Features

**Available in:**

* JSSP
* WebApp
