# BuildQueryEx

Returns generated query and format string

```text
[ String sql, String format ] = queryDef.BuildQueryEx () const
```

## Parameters

None.

## Return value(s)

**sql** Output query

**format** Format string, compatible with the sqlSelect() JavaScript function.
