# PrepareMultipartRelated

Save the images to include in the email in the database

```text
PrepareMultipartRelated ( XML imageList, Boolean embedImages )
```

## Parameters

**imageList** List of images

**embedImages** Forces image inclusion

## Return value(s)

None.

**Schema:** [nms:delivery](s-nms-delivery.md)

**Static:**

Yes
