# StartValidation

Submit the offer for approval.

```text
StartValidation ( String offerId, Number type, XML offerSpaces )
```

## Parameters

**offerId** Offer ID.

**type** Approval type (targeting=0, content=1)

**offerSpaces** Offer spaces to approve

## Return value(s)

None.

## Features

**Schema:** [nms:offer](s-nms-offer.md)

**Static:**

Yes
