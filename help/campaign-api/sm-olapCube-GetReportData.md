# GetReportData

```text
XML result = GetReportData ( Number cubeId, String queryDef, Boolean selectAll, Boolean useAggregates, XML cube )
```

## Parameters

**cubeId** Cube identifier. Can be set to 0 if the cube is passed as a parameter.

**queryDef** QueryDef defined in the report

**selectAll** Select all

**useAggregates** Enable aggregate use

**cube** XML describing the cube.

## Return value(s)

**result** Result

## Features

**Schema:** [xtk:olapCube](s-xtk-olapCube.md)

**Static:**

Yes
