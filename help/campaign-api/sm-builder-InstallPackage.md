# InstallPackage

Install a package.

```text
InstallPackage ( XML parameters )
```

## Parameters

**parameters** XML element containing the package to import.

## Return value(s)

None.

## Remarks

A package generated by the SpecFile.Generate() method must be encapsulated in a builder element. Example:

```javascript
var params =
  {builder:
    {package:
      { ... }
    }
  }

NLWS.xtkBuilder.InstallPackage(params)
```

## Features

**Schema:** [xtk:builder](s-xtk-builder.md)

**Static:**

Yes
