# BuildMirrorEx

Build the HTML mirror page.

```text
[ String content, Number responseCode ] = BuildMirrorEx ( String crypted, XML parameters )
```

## Parameters

**crypted** Reversible crypt for message and delivery part identifiers

**parameters** Parameters

## Return value(s)

**content** Content of the mirror page

**responseCode** HTTP response in case of error

## Features

**Schema:** [nms:delivery](s-nms-delivery.md)

**Static:**

Yes
