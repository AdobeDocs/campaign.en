# toXML

Returns an XML JavaScript object obtained from the content of the [MemoryBuffer](c-memorybuffer.md). This function is obsolete, use [toDocument()](m-memorybuffer-todocument.md)

```text
toXML ( [codePage ])
```

## Parameters

**codePage** An integer coding the page of characters used. By default, MemoryBuffer.CODEPAGE\_UTF8.

## Return value

The content of a stamp in the form of an XML object.
