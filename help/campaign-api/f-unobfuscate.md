# unobfuscate

Unobfuscates the previously obfuscated integer thanks to [obfuscate](f-obfuscate.md).

```text
unobfuscate (value [, version ])
```

## Parameters

**value** The integer to obfuscate.

**version** The unobfuscation version to apply. 0 by default.

## Return value

The integer previously obfuscated by [obfuscate](f-obfuscate.md).
