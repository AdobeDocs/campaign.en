# GenerateAndSaveReport

Generates a report from the server and saves it in the database

```text
XML result = GenerateAndSaveReport ( String reportName, XML context )
```

## Parameters

**reportName** Internal name of the report

**context** Report configuration

## Return value(s)

**result** Unique identifier and record date

## Features

**Schema:** [xtk:report](s-xtk-report.md)

**Static:**

Yes
