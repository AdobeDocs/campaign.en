# digestStrSha512

Calculates the SHA-512 hash of a string of characters. The string is automatically encoded in UTF-8 before the calculation.

```text
digestStrSha512 (string)
```

## Parameters

**string** The string in which the hash is to be calculated.

## Return value

The SHA-512 hash of the string passed as a parameter.

## Features

**Available in:**

* Content management
* Delivery properties
* Delivery message
* Typology rule
* Import
* JSSP
* SOAP Method
* WebApp
* Workflow
