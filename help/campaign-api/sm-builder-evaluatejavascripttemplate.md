# EvaluateJavaScriptTemplate

JavaScript template (JST) evaluation.

```text
[ XML context, String result ] = EvaluateJavaScriptTemplate ( String name, String template, XML context )
```

## Parameters

**name** Script name.

**template** Document to evaluate.

**context** Context when evaluating the document.

## Return value(s)

**context** Context when evaluating the document.

**result** Document resulting from the evaluation.
