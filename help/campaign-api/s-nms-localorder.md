# localOrder

Local campaign orders in a package for distributed marketing

## Methods

| Method | Description |
| --- | --- |
| [Cancel](sm-localorder-cancel.md) | Cancel the order. |
| [CreateFromCatalog](sm-localorder-createfromcatalog.md) | Create an order from a package. |
| [EvaluateContent](sm-localorder-evaluatecontent.md) | Evaluates the content of a delivery linked to an order. This evaluation will be performed when ordering using operator rights and before the local campaign is created. |
| [EvaluateContentFromId](sm-localorder-evaluatecontentfromid.md) | Evaluates the content of a delivery linked to an order. This evaluation will be performed when ordering using operator rights and before the local campaign is created. |
| [EvaluateDeliveryBudget](sm-localorder-evaluatedeliverybudget.md) | Evaluate delivery budget. |
| [EvaluateTarget](sm-localorder-evaluatetarget.md) | Evaluates campaign targeting for each campaign delivery linked to an order. This evaluation will be performed when ordering using operator rights and before the local campaign is created. |
| [EvaluateTargetFromId](sm-localorder-evaluatetargetfromid.md) | Evaluates campaign targeting for each campaign delivery linked to an order. This evaluation will be performed when ordering using operator rights and before the local campaign is created. |
| [ExecuteTarget](sm-localorder-executetarget.md) | Executes the campaign targeting linked to the order. |
| [Reserve](sm-localorder-reserve.md) | Order. |
| [Validation](sm-localorder-validation.md) | Approve the order. |
