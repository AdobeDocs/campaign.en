# DOMDocument (Class)

XML Document.

## Methods

| Method | Description |
| --- | --- |
| [DOMDocument](m-DOMDocument-DOMDocument.md) | Creates a new document. |
| [fromXMLString](m-DOMDocument-fromXMLString.md) | Creates a new document from a string of XML characters. |
| [fromJXON](m-DOMDocument-fromJXON.md) | Creates a new document from a JXON object. |
| [load](m-DOMDocument-load.md) | Creates a new document from an XML file. |
| [toXMLString](m-DOMDocument-toXMLString.md) | Converts the XML document into a string of characters. |
| [createElement](m-DOMDocument-createElement.md) | Creates a new element. |
| [createElementNS](m-DOMDocument-createElementNS.md) | Creates a new element with the specified name and namespace. |
| [createTextNode](m-DOMDocument-createTextNode.md) | Creates a new text type node. |
| [createComment](m-DOMDocument-createComment.md) | Creates a new comment type node. |
| [createCDATASection](m-DOMDocument-createCDATASection.md) | Creates a new CDATA type node. |
| [createProcessingInstruction](m-DOMDocument-createProcessingInstruction.md) | Creates a new processing instruction. |
| [createEntityReference](m-DOMDocument-createEntityReference.md) | Creates a new entity reference. |
| [getElementsByTagName](m-DOMDocument-getElementsByTagName.md) | Returns the list of all elements with the specified name. |
| [getElementsByTagNameNS](m-DOMDocument-getElementsByTagNameNS.md) | Returns the list of all the document elements with the specified name and namespace. |
| [getElementById](m-DOMDocument-getElementById.md) | Returns the element with the specified ID. |
| [importNode](m-DOMDocument-importNode.md) | Creates a node copy from another document. |
| [normalizeDocument](m-DOMDocument-normalizeDocument.md) | Normalizes the document: the entity references are replaced and adjacent text nodes fusioned. |
| [renameNode](m-DOMDocument-renameNode.md) | Changes the name of an element or an attribute. |

| Property | Description |

| [documentURI](p-DOMDocument-documentURI.md) | Document namespace URI. |
