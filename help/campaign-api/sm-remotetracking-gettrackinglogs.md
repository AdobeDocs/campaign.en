# GetTrackingLogs

Enables you to collect the tracking logs generated by the re-direction and webtracking service.

```text
[ String pointer, Number logCount, String logs, Date srvDate ] = GetTrackingLogs ( String instance, String dbId, Number version, String pointer, Number logCount )
```

## Parameters

**instance** Short identifier

**dbId** Database identifier for customer performing a delivery

**version** Tracking log version

**pointer** Identifier (serialized int64) of log from which logs should be retrieved.

**logCount** Number of logs to retrieve for the request (0 means default value), number of logs returned by response.

## Return value(s)

**pointer** Identifier (serialized int64) of log from which logs should be retrieved.

**logCount** Number of logs to retrieve for the request (0 means default value), number of logs returned by response.

**logs** Logs retrieved

**srvDate** GMT time of server at the moment of log retrieval request
