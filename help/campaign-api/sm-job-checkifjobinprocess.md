# CheckIfJobInProcess

Check if the job is still running

```text
Boolean result = CheckIfJobInProcess ( Number pid, String hostName )
```

## Parameters

**pid** Job identifier

**hostName** Name of the machine on which the job has been started

## Return value(s)

**result** Result

## Features

**Schema:** [xtk:job](s-xtk-job.md)

**Static:**

Yes
