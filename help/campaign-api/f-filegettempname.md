# fileGetTempName

Generates a temporary file name.

```text
fileGetTempName ( [directory ] [, prefix ] [, extension ])
```

## Parameters

**directory** Directory of the temporary file. If empty, use the temporary directory defined by the system.

**prefix** Prefix with 4 characters max. If empty, the tmp prefix is used.

**extension** File extension.

## Return value

Full name of the file.
