# DictionaryExport

Exports strings to translate.

```text
XML files = DictionaryExport ( XML where, Number exportOption, String exportFormat )
```

## Parameters

**where** Selection.

**exportOption** Export option

**exportFormat** Export format

## Return value(s)

**files** Description of the output files
