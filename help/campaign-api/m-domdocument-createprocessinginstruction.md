# createProcessingInstruction

Creates a new processing instruction.

```text
createProcessingInstruction (target, data)
```

## Parameters

**target** Processing instruction target, for example &lt;?php ... ?&gt;.

**data** Character string to insert into the instruction.

## Return value

[processinginstruction](c-domnode.md) created.
