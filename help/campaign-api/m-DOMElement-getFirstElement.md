# getFirstElement

Returns the first child element by verifying the given criteria.

```text
getFirstElement (tagName [, attrName ] [, attrValue ])
```

## Parameters

**tagName** Name of searched element.

**attrName** Name of an attribute that has to verify a given value.

**attrValue** Attribute value.

## Return value

First element verifying the given criteria or null.
