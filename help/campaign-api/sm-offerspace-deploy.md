# Deploy

Deploy spaces to an environment.

```text
Deploy ( XML offerSpaceFilter, Number offerEnv )
```

## Parameters

**offerSpaceFilter** Filtering condition defining the spaces to copy

**offerEnv** Identifier of the destination environment

## Return value(s)

None.

## Features

**Schema:** [nms:offerSpace](s-nms-offerspace.md)

**Static:**

Yes
