# HttpClientResponse (Class)

An object which represents the response to an HTTP query.

May only be obtained after the execution of an HTTP query by the `response` property.

## Properties

| Property | Description |
| --- | --- |
| [body](p-HttpClientResponse-body.md) | The body of the HTTP response in the form of a MemoryBuffer object. |
| [code](p-HttpClientResponse-code.md) | The return code of the HTTP response in the form of a JavaScript integer. |
| [codePage](p-HttpClientResponse-codePage.md) | The value of the codePage of the response. Used for decoding the body of the HTTP response. |
| [header](p-HttpClientResponse-header.md) | An object which contains all the HTTP headers. |
| [headers](p-HttpClientResponse-headers.md) | The list of headers for the HTTP response grouped by name. |
| [message](p-HttpClientResponse-message.md) | The message carried by the HTTP response. |
