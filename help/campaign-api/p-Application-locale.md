# locale

Returns a caracter string that matches the instance Local.

```text
locale
```

## Remarks

The Local is a code that defintes regional settings. It is made up of a language code followed by a country code, separated by '-'. Examples of values:

* en-US - English, United States
* en-GB - English, Great Britain
* fr-FR - French, France
* de-DE - German, Germany
* es-ES - Spanish, Spain
