# save

Saves the archive.

```text
save ( [filename ] [, overwrite ])
```

## Parameters

**filename** Name of the archive. If the name is not specified or is empty, the archive is saved under its original name.

**overwrite** If 'false', the archive will not be saved if a file already exists with this name, and an exception will be raised.

## Return value

None.
