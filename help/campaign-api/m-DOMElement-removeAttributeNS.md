# removeAttributeNS

Delete an attribute.

```text
removeAttributeNS (namespaceURI, localName)
```

## Parameters

**namespaceURI** URI of the attribute namespace.

**localName** Attribute name.

## Return value

None.

## Remarks

The method has no effect if the element has no attribute of this name.
