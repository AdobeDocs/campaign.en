# DeploySQLFunctions

Deploys the functions required by Adobe Campaign Federated Data Access on the remote RDBMS server

```text
DeploySQLFunctions ( String extAccountId )
```

## Parameters

**extAccountId** Internal Name or PrimaryKey of the external Account

## Return value(s)

None.

## Features

**Schema:** [nms:extAccount](s-nms-extAccount.md)

**Static:**

Yes
