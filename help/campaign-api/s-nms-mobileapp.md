| Method | Description |
| --- | --- |

| [iOSGenerateCertificate](sm-mobileapp-iosgeneratecertificate.md) | Encodes the provided iOS certificate in base64 |
| [iOSResetConnectionCache](sm-mobileapp-iosresetconnectioncache.md) | Reinitialize the APNS connections' cache |
| [iOSTestConnection](sm-mobileapp-iostestconnection.md) | Tests APNS connection using the application parameters |
| [resetServiceMobileAppsCustomHook](sm-mobileapp-resetservicemobileappscustomhook.md) | Erases the additional parameters of web services for all mobileApps in the same service |
