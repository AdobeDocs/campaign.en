# EvaluateDeliveryBudget

Evaluate delivery budget.

```text
Number result = EvaluateDeliveryBudget ( Number deliveryId, Number nbMessage )
```

## Parameters

**deliveryId** Delivery ID.

**nbMessage** Number of messages to send.

## Return value(s)

**result** Evaluated budget.
