# resetServiceMobileAppsCustomHook

Erases the additional parameters of web services for all mobileApps in the same service

```text
XML serviceOut = resetServiceMobileAppsCustomHook ( XML serviceContent )
```

## Parameters

**serviceContent** Content of the current service node

## Return value(s)

**serviceOut** Content of the service node after processing

## Features

**Schema:** [nms:mobileApp](s-nms-mobileapp.md)

**Static:**

Yes
