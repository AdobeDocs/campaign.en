# AddInstance

> Warning: This function is available for an on-Premise environment.

Declares a new instance on the server

```text
AddInstance ( String instanceName, String hosts, String lang )
```

## Parameters

**instanceName** Name of the instance to create

**hosts** DNS masks associated with the instance

**lang** Instance language

## Return value(s)

None.

## Features

**Schema:** [xtk:serverOptions](s-xtk-serveroptions.md)

**Static:**

Yes
