# getEventFromTransition

Returns the last event to undergo a given transition.

```text
getEventFromTransition (transitionName)
```

## Parameters

**transitionName** The internal name of the transition.

## Return value

The last event to have undergone given transition or null. The object corresponds to an entity in the 'xtk:workflowEvent' schema.

**Available in:**

* Workflow
