# setContentType

Changes the document type of the response.

```text
setContentType (name)
```

## Parameters

**name** MIME type of the document.

## Return value

None.

## Remarks

Example:

```javascript
      response.setContentType("text/html;charset=ISO-8859-1")
```

## Features

**Method of class:** [HttpServletResponse](c-HttpServletResponse.md)

**Available in:**

* JSSP
