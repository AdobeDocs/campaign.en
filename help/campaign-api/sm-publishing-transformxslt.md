# TransformXSLT

XSLT based publishing transformation

```text
String result = TransformXSLT ( String source, String namespace, String format, String contentId )
```

## Parameters

**source** XSLT stylesheet content

**namespace** Namespace used for relative xsl:import directives

**format** Output format

**contentId** Content identifier

## Return value(s)

**result** Transformation result

## Features

**Schema:** [ncm:publishing](s-ncm-publishing.md)

**Static:**

Yes
