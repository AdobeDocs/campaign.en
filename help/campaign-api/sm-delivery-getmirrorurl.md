# GetMirrorURL

Obtains the URL of an HTML mirror page.

```text
String url = GetMirrorURL ( Number deliveryId, String message )
```

## Parameters

**deliveryId** Delivery identifier

**message** Message ID

## Return value(s)

**url** Mirror page URL

## Features

**Schema:** [nms:delivery](s-nms-delivery.md)

**Static:**

Yes
