# Cookie (Class)

Represents a cookie exchanged by the servlet and the web browser.

## Properties

| Property | Description |
| --- | --- |
| [name](p-Cookie-name.md) | Cookie name. |
| [comment](p-Cookie-comment.md) | Comment describing the function of the cookie, null if undefined. |
| [domain](p-Cookie-domain.md) | Cookie's domain name. |
| [maxAge](p-Cookie-maxAge.md) | Cookie life-span in seconds. |
| [path](p-Cookie-path.md) | Path based on which the web browser forwards the cookie. |
| [secure](p-Cookie-secure.md) | true if the cookie can only be forwarded via a secure protocol. |
| [value](p-Cookie-value.md) | Cookie value. |
| [version](p-Cookie-version.md) | Protocol version which the cookie is compatible with. |

## Features

**Available in:**

* JSSP
* WebApp
