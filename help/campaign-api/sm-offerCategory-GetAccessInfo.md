# GetAccessInfo

Returns the inherited properties of the anonymous mode.

```text
[ Boolean anonymous, Boolean parentAnonymous ] = GetAccessInfo ( Number categoryId )
```

## Parameters

**categoryId** Category ID

## Return value(s)

**anonymous** Specifies whether or not the category offers are anonymous

**parentAnonymous** Specifies whether or not the parent category offers are anonymous

## Features

**Schema:** [nms:offerCategory](s-nms-offerCategory.md)

**Static:**

Yes
