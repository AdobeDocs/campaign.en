# DropSelection

Move selection into a navigation tree folder

```text
DropSelection ( String schema, String entityFolder, XML selectionList, Number folderDestId )
```

## Parameters

**schema** Selection schema Id

**entityFolder** Id of the destination folder

**selectionList** Selection to move

**folderDestId** Destination folder

## Return value(s)

None.

## Features

**Schema:** [xtk:folder](s-xtk-folder.md)

**Static:**

Yes
