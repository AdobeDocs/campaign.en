# setFile

> Warning:
>
> Access via file APIs is limited to the **var**, **sftp** and temporary folders of Adobe Campaign.

Defines the transfer mode and the receiving file.

```text
setFile (filename)
```

## Parameters

**filename** Name of the local file.

## Return value

None.

## Features

**Method of class:** [FTP](c-ftp.md)

**Available in:**

* Content management
* Delivery properties
* Typology rule
* JSSP
* SOAP Method
* WebApp
* Workflow
