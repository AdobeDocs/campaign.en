# getNumberValue

Returns the digital node value referenced by the given XPath.

```text
getNumberValue (xpath)
```

## Parameters

**xpath** Path.

## Return value

Digital value corresponds to the node referenced.

## Remarks

The syntax for the XPath only accepts an XPath language subset. An exception is raised if the path is badly formed or if the value is not a valid number.
