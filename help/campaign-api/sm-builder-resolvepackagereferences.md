# ResolvePackageReferences

Solves dependencies in the package

```text
[ XML patchedPackage, Number warningNb ] = ResolvePackageReferences ( XML parameters )
```

## Parameters

**parameters** XML element containing the package to import.

## Return value(s)

**patchedPackage** Processed package.

**warningNb** Number of warnings generated.

## Features

**Schema:** [xtk:builder](s-xtk-builder.md)

**Static:**

Yes
