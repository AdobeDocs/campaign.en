# applyXsl

Transforms an XML document using an XSL style sheet.

```text
applyXsl (xslEntity, xml)
```

## Parameters

**xslEntity** The name of the XSL style sheet stored in the database.

**xml** An XML document or a character string containing the XML document to transform.

## Return value

The XML document in the form of a character string after transformation.

## Features

**Available in:**

* Content management
* Delivery properties
* Typology rule
* JSSP
* SOAP Method
* WebApp
* Workflow
