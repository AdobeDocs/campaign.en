# CreateTrackingInstance

Create or configure a tracking instance on a redirection server

```text
CreateTrackingInstance ( String internalPwd, String serverUrl, String secureServerUrl, String serverUrlList, String instanceName, String cryptedPassword, String host )
```

## Parameters

**internalPwd** Internal password

**serverUrl** External URL of the tracking server

**secureServerUrl** External secure URL of the tracking server

**serverUrlList** Internal URLs of the tracking servers

**instanceName** Name of the instance to create

**cryptedPassword** Encrypted password

**host** DNS masks associated with the instance

## Return value(s)

None.

## Features

**Schema:** [nms:trackingUrl](s-nms-trackingUrl.md)

**Static:**

Yes
