# exportSaved

Export saved report from history table

```text
exportSaved ( String reportHistoryId, String exportFormat, String fileName )
```

## Parameters

**reportHistoryId** Report history ID

**exportFormat** Export format

**fileName** Output file name

## Return value(s)

None.

**Schema:** [xtk:report](s-xtk-report.md)

**Static:**

Yes
