# Submit

Submits a job for an asynchronous processing

```text
String id = job.Submit ( String methodName ) const
```

## Parameters

**methodName** Name of the method to call on entity

## Return value(s)

**id** Identifier of job just created

**Schema:** [xtk:job](s-xtk-job.md)

No

**Const:**

Yes
