# GetUsedLanguagesEnum

Creates an enumeration with the languages used in the Web application.

```text
XML enum = GetUsedLanguagesEnum ( String designLanguage, String defaultLanguage, XML additionalLanguages )
```

## Parameters

**designLanguage** Design language

**defaultLanguage** Default language

**additionalLanguages** Other languages

## Return value(s)

**enum** Enumeration with the languages used

## Features

**Schema:** [nms:webApp](s-nms-webapp.md)

**Static:**

Yes
