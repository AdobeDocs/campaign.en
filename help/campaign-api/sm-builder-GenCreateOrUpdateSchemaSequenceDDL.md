# GenCreateOrUpdateSchemaSequenceDDL

Generates the SQL script used to create or update autoPk schema sequence

```text
String sqlDDL = GenCreateOrUpdateSchemaSequenceDDL ( String schemaId, String newSequence, String oldSequence )
```

## Parameters

**schemaId** Schema identifier

**newSequence** New sequence

**oldSequence** Old sequence

## Return value(s)

**sqlDDL** SQL script

## Features

**Schema:** [xtk:builder](s-xtk-builder.md)

**Static:**

Yes
