# dataTransfer

Data transfer scripts (import/export)

## Methods

| Method | Description |
| --- | --- |
| [AutoDetect](sm-dataTransfer-AutoDetect.md) | Start an auto-detection and return the first lines of the file |
| [Cleanup](sm-dataTransfer-Cleanup.md) | Purge history from the executed instance |
| [ExportPreview](sm-dataTransfer-ExportPreview.md) | Compute output file column preview for the first lines of the query |
| [GetFilesToDownload](sm-dataTransfer-GetFilesToDownload.md) | Returns the list of files used by this transfer and found on the server |
| [RejectExport](sm-dataTransfer-RejectExport.md) | Starts the export of the rejects |
| [Start](sm-dataTransfer-Start.md) | Starts the data transfer |
| [TestCalcField](sm-dataTransfer-TestCalcField.md) | Test the calculated field using the sample lines stored in the script. |

## Generic Methods

| Method | Description |
| --- | --- |
| [create](f-create.md) | Creates a new entity corresponding to a given schema. |
| [load](f-load.md) | Loads and returns an entity corresponding to a given schema and key. |
| [save](m-Entity-save.md) | Saves an entity in the database. |
