# CreateInstanceFromModel

Instantiates an instance of an object via a template

```text
Number output = CreateInstanceFromModel ( String schema, Number modelId, XML diff )
```

## Parameters

**schema** Instance schema

**modelId** ID of the template

**diff** XML patch to apply to the template

## Return value(s)

**output** ID of the created instance

## Features

**Schema:** [xtk:queryDef](s-xtk-querydef.md)

**Static:**

Yes
