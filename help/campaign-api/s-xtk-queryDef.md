# queryDef

Definition of queries

## Methods

| Method | Description |
| --- | --- |
| [BuildQuery](sm-queryDef-BuildQuery.md) | Returns generated query |
| [BuildQueryEx](sm-queryDef-BuildQueryEx.md) | Returns generated query and format string |
| [CreateInstanceFromModel](sm-queryDef-CreateInstanceFromModel.md) | Instantiates an instance of an object via a template |
| [DisplayCondition](sm-queryDef-DisplayCondition.md) | Builds a representation of the query |
| [EvaluateExpr](sm-queryDef-EvaluateExpr.md) | Evaluate an expression by the database |
| [ExecuteQuery](sm-queryDef-ExecuteQuery.md) | Retrieve data from a query |
| [GetInstanceFromModel](sm-queryDef-GetInstanceFromModel.md) | Retrieve the data of an instance created from a template |
| [SelectAll](sm-queryDef-SelectAll.md) | Adds all fields in the select part. |
| [Update](sm-queryDef-Update.md) | Mass update of the selection |
