# GenerateForDelivery

Generates a content for a delivery

```text
XML result = GenerateForDelivery ( String contentId, String scenarioId )
```

## Parameters

**contentId** Content identifier

**scenarioId** Identifier of delivery template

## Return value(s)

**result** Result
