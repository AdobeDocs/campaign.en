# CheckValidationAccess

Verifies whether the current operator is able to review the delivery.

```text
Boolean result = CheckValidationAccess ( XML validation, Number ownerId, Number type )
```

## Parameters

**validation** Approval parameters

**ownerId** Owner ID

**type** Approval type

## Return value(s)

**result** Method return value (yes/no)
