# CreateTrackingInstanceShell

Create or configure a tracking instance on a redirection server

```text
CreateTrackingInstanceShell ( String internalPwd, String serverUrlList, String instanceName, String cryptedPassword, String host )
```

## Parameters

**internalPwd** Internal password

**serverUrlList** Internal URLs of the tracking servers

**instanceName** Name of the instance to create

**cryptedPassword** Encrypted password

**host** DNS masks associated with the instance

## Return value(s)

None.

## Features

**Schema:** [nms:trackingUrl](s-nms-trackingUrl.md)

**Static:**

Yes
