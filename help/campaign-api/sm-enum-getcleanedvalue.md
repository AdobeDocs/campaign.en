# GetCleanedValue

Get a cleansed value.

```text
String value = GetCleanedValue ( Number enumId, String alias )
```

## Parameters

**enumId** Enumeration ID

**alias** Value to replace

## Return value(s)

**value** Cleansed value (if not found, returns the alias)

## Features

**Schema:** [xtk:enum](s-xtk-enum.md)

**Static:**

Yes
