# setIdAttributeNS

Declares the specified attribute as an ID type attribute.

```text
setIdAttributeNS (namespaceURI, localName)
```

## Parameters

**namespaceURI** URI of the attribute namespace.

**localName** Attribute name.

## Return value

None.
