# updateFacebookProfile

```text
Number result = updateFacebookProfile ( String accessToken )
```

## Parameters

**accessToken**

## Return value(s)

**result** Returns the ID of the Adobe Campaign entity that matches the Facebook access token. If the code is different from 0, the call was successful.
