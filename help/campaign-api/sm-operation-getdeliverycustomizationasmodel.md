# GetDeliveryCustomizationAsModel

Copy the selected personalization field templates.

```text
XML parentOut = GetDeliveryCustomizationAsModel ( XML selection, XML parentIn )
```

## Parameters

**selection** Element containing the selected template identifiers

**parentIn** Element containing the existing personalizations

## Return value(s)

**parentOut** Returns the element with the new templates added

## Features

**Schema:** [nms:operation](s-nms-operation.md)

**Static:**

Yes
