# remoteTracking

Access to the remote tracking management service

## Methods

| Method | Description |
| --- | --- |
| [CreateInstance](sm-remoteTracking-CreateInstance.md) | Used to create a tracking instance |
| [CreateInstanceEx](sm-remoteTracking-CreateInstanceEx.md) | Used to create a tracking instance |
| [GetTrackingInfo](sm-remoteTracking-GetTrackingInfo.md) | Allows a remote redirection server to download information about a delivery action. |
| [GetTrackingLogs](sm-remoteTracking-GetTrackingLogs.md) | Enables you to collect the tracking logs generated by the re-direction and webtracking service. |
| [GetTrackingLogs4](sm-remoteTracking-GetTrackingLogs4.md) | Allows to retrieve the tracking logs generated by the remote redirection and webtracking server, using a post 4.00 format. |
| [PushRelayInfo](sm-remoteTracking-PushRelayInfo.md) | Lets you upload information on a delivery to the remote tracking servers. |
| [PushTrackingInfo](sm-remoteTracking-PushTrackingInfo.md) | Allows to upload on remote tracking server all information regarding a delivery. |
| [RegisterInstance](sm-remoteTracking-RegisterInstance.md) | Used to approve a tracking instance |
