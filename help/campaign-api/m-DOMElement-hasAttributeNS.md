# hasAttributeNS

Test an attribute's existence.

```text
hasAttributeNS (namespaceURI, localName)
```

## Parameters

**namespaceURI** URI of the attribute namespace.

**localName** Attribute name.

## Return value

true if the attribute exists, otherwise false.
