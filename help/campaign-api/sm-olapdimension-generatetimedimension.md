# GenerateTimeDimension

Generate a time domain.

```text
XML result = GenerateTimeDimension ( XML dimension, XML field, XML dates )
```

## Parameters

**dimension** Dimension to enter

**field** Field or expression used

**dates** Date description

## Return value(s)

**result** Entered dimension

## Features

**Schema:** [xtk:olapDimension](s-xtk-olapdimension.md)

**Static:**

Yes
