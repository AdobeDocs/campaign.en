# SubmitDelivery

Creation and submission of a delivery from a scenario (from its internal name).

```text
Number deliveryId = SubmitDelivery ( String scenarioName, XML content )
```

## Parameters

**scenarioName** Internal name of the delivery template

**content** XML content to add to the template

## Return value(s)

**deliveryId** Identifier of the new delivery (returned even if the analysis fails)

## Features

**Schema:** [nms:delivery](s-nms-delivery.md)

**Static:**

Yes
