# GetDbParams

Retrieves current parameters of datasource.

```text
[ XML dbcnx, XML dbParameters ] = GetDbParams ()
```

## Parameters

None.

## Return value(s)

**dbcnx** Data source definition

**dbParameters** Update the namespaces and tablespaces.

## Features

**Schema:** [xtk:builder](s-xtk-builder.md)

**Static:**

Yes
