# DOMDocument

Creates a new document.

```text
DOMDocument (name [, namespaceURI ])
```

## Parameters

**name** Document name.

**namespaceURI** Document namespace URI.

## Return value

None.

## Remarks

Example:

```javascript
var doc = new DOMDocument("test")
var doc2 = new DOMDocument("html", "http://www.w3.org/1999/xhtml")
```
