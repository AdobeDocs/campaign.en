# Entity (Class)

Represents an entity of the database for a given schema.

Such an object cannot be instantiated directly. You must use the methods create(), get() or load().

## Methods

| Method | Description |
| --- | --- |
| [save](m-Entity-save.md) | Saves an entity in the database. |

## Features

**Available in:**

* Content management
* Delivery properties
* Typology rule
* JSSP
* SOAP Method
* WebApp
* Workflow
