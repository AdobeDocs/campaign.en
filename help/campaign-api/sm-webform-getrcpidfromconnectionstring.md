# GetRcpIdFromConnectionString

Returns the identifier of a recipient according to the connection string

```text
[ String id, String cryptedId ] = GetRcpIdFromConnectionString ( String connectionString )
```

## Parameters

**connectionString** Connection string

## Return value(s)

**id** External identifier

**cryptedId** Encrypted identifier

Yes
