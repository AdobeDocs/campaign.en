# CompleteTaskOperation

Completes a task created in the context of a campaign.

```text
XML taskOut = CompleteTaskOperation ( XML taskIn, XML parameter )
```

## Parameters

**taskIn** Inbound task

**parameter** Configuration of the campaign context

## Return value(s)

**taskOut** Update task

## Features

**Schema:** [nms:operation](s-nms-operation.md)

**Static:**

Yes
