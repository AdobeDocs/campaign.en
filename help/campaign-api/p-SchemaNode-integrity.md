# integrity

Returns the link integrity type.

```text
integrity
```

## Remarks

The property can take one of the following values:

* Schema.INTEGRITY\_NORMAL - "Normal" type link.
* Schema.INTEGRITY\_DEFINE - "Define" type link.
* Schema.INTEGRITY\_NEUTRAL - "neutral" type link.
* Schema.INTEGRITY\_USED - "used" type link.
* Schema.INTEGRITY\_OWN - "own" type link.
* Schema.INTEGRITY\_OWNCOPY - "owncopy" type link.
