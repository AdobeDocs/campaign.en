# conflict

> Warning: This function is available for an on-Premise environment.

Temporary storage of the conflicting entities.

## Methods

| Method | Description |
| --- | --- |
| [AcceptCus](sm-conflict-AcceptCus.md) | Keeps the current version. |
| [AcceptNew](sm-conflict-AcceptNew.md) | Accepts the new version as the current version. |
| [SetResolved](sm-conflict-SetResolved.md) | Declares an entity as having no more conflicts. |

## Generic Methods

| Method | Description |
| --- | --- |
| [create](f-create.md) | Creates a new entity corresponding to a given schema. |
| [load](f-load.md) | Loads and returns an entity corresponding to a given schema and key. |
| [save](m-Entity-save.md) | Saves an entity in the database. |
