# DeliveryValidation

Approval of a delivery in a campaign.

```text
DeliveryValidation ( Number deliveryId, Number type, Boolean refused, String comment )
```

## Parameters

**deliveryId** Delivery identifier

**type** Approval type (targeting=0, content=1, budget=2, extraction=3)

**refused** Reject

**comment** Comment

## Return value(s)

None.
