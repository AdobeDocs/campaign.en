# EnumerationValue (Class)

Represents the definition of an enumeration value.

## Properties

| Property | Description |
| --- | --- |
| [label](p-EnumerationValue-label.md) | Returns a string of characters which provide the short description of the current enumeration value. |
| [description](p-EnumerationValue-description.md) | Returns a string of characters which provides the description of the current enumeration value. |
| [value](p-EnumerationValue-value.md) | Returns a string of characters which provides the value of the current enumeration value. |
| [name](p-EnumerationValue-name.md) | Returns a string of characters which provides the name of the current enumeration value. |
| [image](p-EnumerationValue-image.md) | Returns a string of characters which provides the name of the image of the current enumeration value. |
| [enabledIf](p-EnumerationValue-enabledIf.md) | Returns a string of characters which provides the validity conditions of the current enumeration value. |
