# UpdateBinningClass

Update a bin by generating its label and condition.

```text
XML result = UpdateBinningClass ( XML binning, String exprType )
```

## Parameters

**binning** Current binning

**exprType** Level expression type

## Return value(s)

**result** Binning updated

## Features

**Schema:** [xtk:olapCube](s-xtk-olapcube.md)

**Static:**

Yes
