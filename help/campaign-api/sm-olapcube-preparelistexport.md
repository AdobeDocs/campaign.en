# PrepareListExport

```text
XML translatedConditions = PrepareListExport ( Number cubeId, XML cube, XML conditions )
```

## Parameters

**cubeId** Cube identifier

**cube** Serialized XML describing the cube.

**conditions** List of selections

## Return value(s)

**translatedConditions** Conditions on the fact schema

## Features

**Schema:** [xtk:olapCube](s-xtk-olapcube.md)

**Static:**

Yes
