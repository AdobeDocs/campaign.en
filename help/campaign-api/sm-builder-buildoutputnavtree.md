# BuildOutputNavTree

Merge the navigation tree definitions found in the database with the one given in parameter.

```text
XML navtree = BuildOutputNavTree ( XML navtreeSource, Boolean save )
```

## Parameters

**navtreeSource** Source navigation tree

**save** Save the result

## Return value(s)

**navtree** Result of the merge

## Features

**Schema:** [xtk:builder](s-xtk-builder.md)

**Static:**

Yes
