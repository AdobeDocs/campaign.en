# HasWarning

Queries if warnings or errors have been generated for this job

```text
Boolean hasWarning = HasWarning ( String id )
```

## Parameters

**id** Job identifier

## Return value(s)

**hasWarning** Returns 'true' if there has been at least one warning or error message

## Features

**Schema:** [xtk:job](s-xtk-job.md)

**Static:**

Yes
