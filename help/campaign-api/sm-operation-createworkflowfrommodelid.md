# CreateWorkflowFromModelId

Create a workflow in a campaign based on a workflow template.

```text
Number workflowId = CreateWorkflowFromModelId ( Number modelId, XML operationPlanning )
```

## Parameters

**modelId** Workflow template identifier

**operationPlanning** Campaign schedule

## Return value(s)

**workflowId** Identifier of the instance created

## Features

**Schema:** [nms:operation](s-nms-operation.md)

**Static:**

Yes
