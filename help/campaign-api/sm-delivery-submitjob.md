# SubmitJob

Submits a job for a delivery for asynchronous processing

```text
SubmitJob ( String methodName, Number id )
```

## Parameters

**methodName** Name of the method to call on entity

**id** Delivery identifier

## Return value(s)

None.

## Features

**Schema:** [nms:delivery](s-nms-delivery.md)

**Static:**

Yes
