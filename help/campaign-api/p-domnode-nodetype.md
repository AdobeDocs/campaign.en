# nodeType

Node type.

```text
nodeType
```

## Remarks

Possible values are:

* 1 Elément
* 2 Attribute
* 3 Text
* 4 CDATA
* 5 Entity reference
* 6 Entity
* 7 Processing instruction
* 8 Comment
* 9 Document
* 10 Document type
* 11 Document fragment
* 12 Notation
