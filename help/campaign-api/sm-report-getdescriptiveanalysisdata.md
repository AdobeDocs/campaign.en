# GetDescriptiveAnalysisData

Executes the query to get descriptive analysis data.

```text
XML data = GetDescriptiveAnalysisData ( XML entity, XML context )
```

## Parameters

**entity** XML document describing the chart

**context** XML context used to filter the data

## Return value(s)

**data** Data in XML format

## Features

**Schema:** [xtk:report](s-xtk-report.md)

**Static:**

Yes
