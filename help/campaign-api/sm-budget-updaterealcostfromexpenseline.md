# UpdateRealCostFromExpenseLine

Updates the actual delivery or task amount using the line item.

```text
UpdateRealCostFromExpenseLine ( Number id, String schema, XML budgetParameters )
```

## Parameters

**id** Delivery/Task identifier

**schema** Entity schema (delivery/task)

**budgetParameters** Budget item on the entity

## Return value(s)

None.

## Features

**Schema:** [nms:budget](s-nms-budget.md)

**Static:**

Yes
