# AutoDetect

Start an auto-detection and return the first lines of the file

```text
XML result = AutoDetect ( String fileName, Number codepage )
```

## Parameters

**fileName** File name

**codepage** Character encoding

## Return value(s)

**result** Returns the first lines of the file

## Features

**Schema:** [xtk:dataTransfer](s-xtk-dataTransfer.md)

**Static:**

Yes
