# PathEdit

Control to select a field.

## Properties

**backColor - string** Background color (btnshadow, white).

**border - string** Changes the control outline style (solid, double, inset, outset, none).

**font-size - integer** Changes the font size.

**hideCalculated - boolean** Hides calculated fields.

**hideMappedAsXml - boolean** Hides XML fields.

**label - string** Associated label.

**nolabel - boolean** Hides the associated label.

**noTransaction - boolean** Disables transactional mode.

**readOnly - boolean** Forces the control to read only.

**required - boolean** The field is mandatory.

**useLink11Path - boolean** Shows 1:1 links.

**useTablePath - boolean** Shows tables.

**useUnboundPath - boolean** Shows collections.

**xpath - string** The field to edit.

**xpathBaseType - xpath** Path for storing the type of the selected field.

**xpathDataPolicy - xpath** Path for storing the dataPolicy property of the selected field.

**xpathEnum - xpath** Path for storing the system enumeration of the selected field.

**xpathLabel - string** Path for storing the label of the selected field.

**xpathSchema - string** Schema path.

**xpathSchemaMd5 - xpath** Path for storing the MD5 of the schema.

**xpathStartPath - string** Path of the startPath (only used if xpathSchema is defined).

**xpathUnbound - xpath** Path for storing the unbound property of the selected field.

**xpathUserEnum - xpath** Path for storing the free enumeration of the selected field.

**xpathType - xpath** Path for storing default control of the selected field.

**zoom - boolean** Shows the edit button.
