# ZipFile (Class)

Manipulates Zip files.

## Methods

| Method | Description |
| --- | --- |
| [ZipFile](m-ZipFile-ZipFile.md) | Creates a new Zip object associated with a file. |
| [dispose](m-ZipFile-dispose.md) | Frees the resources used by the object. |
| [open](m-ZipFile-open.md) | Loads an existing archive. |
| [getEntry](m-ZipFile-getEntry.md) | Extracts a file from the archive. |
| [setEntry](m-ZipFile-setEntry.md) | Adds or updates a file in the archive. |
| [save](m-ZipFile-save.md) | Saves the archive. |

## Properties

| Property | Description |
| --- | --- |
| [fileCount](p-ZipFile-fileCount.md) | Returns the number of files in the archive. |
