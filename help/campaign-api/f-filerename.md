# fileRename

Changes the name of a file.

If the character encoding is not specified, the server default is used.

```text
fileRename (oldname, newname)
```

## Parameters

**oldname** The full name of the file to rename.

**newname** The new name of the file.

## Return value

None.

## Features

**Available in:**

* Content management
* Delivery properties
* Typology rule
* JSSP
* SOAP Method
* WebApp
* Workflow
