# CheckValidationAccess

Verifies whether the current operator is able to review the resource.

```text
Boolean result = CheckValidationAccess ( XML validation, Number ownerId )
```

## Parameters

**validation** Approval parameters

**ownerId** Identifier of the assignee (owner)

## Return value(s)

**result** Method return value (yes/no)

## Features

**Schema:** [nms:asset](s-nms-asset.md)

**Static:**

Yes
