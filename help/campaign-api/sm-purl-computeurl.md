# ComputeUrl

Generates the URL for accessing this pURL

```text
[ String url, String exampleUrl ] = ComputeUrl ( XML purl )
```

## Parameters

**purl** The current purl.

## Return value(s)

**url** URL (technical)

**exampleUrl** URL containing fictive data (for the display)

## Features

**Schema:** [nms:purl](s-nms-purl.md)

**Static:**

Yes
