# GetCompatibleOfferViews

Returns the list of representations compatible with this offer.

```text
XML offerViews = GetCompatibleOfferViews ( Number offerId )
```

## Parameters

**offerId** Offer ID

## Return value(s)

**offerViews** Compatible representations

## Features

**Schema:** [nms:offer](s-nms-offer.md)

**Static:**

Yes
