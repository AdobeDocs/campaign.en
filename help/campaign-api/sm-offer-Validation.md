# Validation

Offer approval.

```text
Validation ( Number offerId, Number type, XML offerSpaces, Boolean refused, String comment )
```

## Parameters

**offerId** Offer ID

**type** Approval type (targeting=0, content=1)

**offerSpaces** Offer spaces to approve

**refused** Reject eligibility approval

**comment** Comment

## Return value(s)

None.

## Features

**Schema:** [nms:offer](s-nms-offer.md)

**Static:**

Yes
