# CreateExportList

Creates the list which the entities in the cart will be exported into.

```text
Number listId = CreateExportList ( String label, Number folderId )
```

## Parameters

**label** Label of the list

**folderId** ID of the folder which the list will be created in (0 to use the default folder).

## Return value(s)

**listId** ID of the newly created list

## Features

**Schema:** [xtk:olapCube](s-xtk-olapcube.md)

**Static:**

Yes
