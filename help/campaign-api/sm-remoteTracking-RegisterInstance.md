# RegisterInstance

Used to approve a tracking instance

```text
RegisterInstance ( String instanceName, String dbId, String lang )
```

## Parameters

**instanceName** Name of the instance to approve

**dbId** Database identifier for customer performing a delivery

**lang** Instance language

## Return value(s)

None.

## Features

**Schema:** [nms:remoteTracking](s-nms-remoteTracking.md)

**Static:**

Yes
