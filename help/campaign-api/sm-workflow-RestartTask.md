# RestartTask

Forces restarting of one or more finished tasks.

```text
RestartTask ( String workflowId, String activityName )
```

## Parameters

**workflowId** Identifier or internal name of the workflow.

**activityName** Name of activity(ies) to restart

## Return value(s)

None.

## Features

**Schema:** [xtk:workflow](s-xtk-workflow.md)

**Static:**

Yes
