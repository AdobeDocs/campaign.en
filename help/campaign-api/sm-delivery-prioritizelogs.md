# PrioritizeLogs

Prioritize the delivery log for a list of deliveries

```text
PrioritizeLogs ( Number id, XML deliveries, String logTable )
```

## Parameters

**id** Prioritization unique identifier

**deliveries** list of deliveries to take into account

**logTable** table containing all the log messages

## Return value(s)

None.

## Features

**Schema:** [nms:delivery](s-nms-delivery.md)

**Static:**

Yes
