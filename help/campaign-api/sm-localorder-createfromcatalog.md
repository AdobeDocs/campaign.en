# CreateFromCatalog

Create an order from a package.

```text
XML localOrder = CreateFromCatalog ( Number catalogId, Number orgUnitId )
```

## Parameters

**catalogId** Package ID.

**orgUnitId** Local entity ID. (optional)

## Return value(s)

**localOrder** Return the created order.

## Features

**Schema:** [nms:localOrder](s-nms-localorder.md)

**Static:**

Yes
