# CalculateNextReminderDate

Calculates the next reminder date (empty if none).

```text
Date parentOut = CalculateNextReminderDate ( Date lastReminderDate, Date expectedDate, XML parameter )
```

## Parameters

**lastReminderDate** Last reminder date used

**expectedDate** Approval date

**parameter** Configuration

## Return value(s)

**parentOut** Result

## Features

**Schema:** [nms:operation](s-nms-operation.md)

**Static:**

Yes
