# PushRelayInfo

Lets you upload information on a delivery to the remote tracking servers.

```text
PushRelayInfo ( String instance, String dbId, XML document )
```

## Parameters

**instance** Instance name

**dbId** Customer database identifier

**document** Document containing data

## Return value(s)

None.

## Features

**Schema:** [nms:remoteTracking](s-nms-remoteTracking.md)

**Static:**

Yes
