# simulation

This schema represents a simulation for a set of deliveries or offers to a population.

## Methods

| Method | Description |
| --- | --- |
| [AddDeliveries](sm-simulation-adddeliveries.md) | Add deliveries in the scope of the delivery. |
| [AddOperations](sm-simulation-addoperations.md) | Add campaigns in the scope of the delivery. |
| [AddPlans](sm-simulation-addplans.md) | Add campaigns in the scope of the delivery. |
| [AddPrograms](sm-simulation-addprograms.md) | Add campaigns in the scope of the delivery. |
| [Schedule](sm-simulation-schedule.md) | Schedules execution of the simulation. |
| [SimulateDeliveries](sm-simulation-simulatedeliveries.md) | Starts a delivery simulation. |
| [SimulateOffers](sm-simulation-simulateoffers.md) | Executes the simulation. |
| [Start](sm-simulation-start.md) | Starts a simulation, in the context of a job. |
| [Stop](sm-simulation-stop.md) | Ends a simulation in progress. |
