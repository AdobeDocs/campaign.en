# RegisterGroup2

Add selected recipients to a list

```text
RegisterGroup2 ( XML groupList, XML recipientList, XML clearGroup )
```

## Parameters

**groupList** Lists

**recipientList** Recipient list

**clearGroup** Recreate list

## Return value(s)

None.

## Features

**Schema:** [nms:recipient](s-nms-recipient.md)

**Static:**

Yes
