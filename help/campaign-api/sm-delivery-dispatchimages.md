# DispatchImages

Tells the application server to send the images to the mid-sourcing server.

```text
DispatchImages ( String images, Number providerId, String providerName )
```

## Parameters

**images** List of images to upload to the mid-sourcing server.

**providerId** Identifier of the delivery router.

**providerName** Name of the delivery router.

## Return value(s)

None.
