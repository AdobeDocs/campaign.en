# toString

Returns the content of the [MemoryBuffer](c-memorybuffer.md) in the form of a string of characters.

```text
toString ( [codePage ])
```

## Parameters

**codePage** An integer which codes the page of characters used. By default, MemoryBuffer.CODEPAGE\_UTF8.

## Return value

The content of a stamp in the form of a string of characters.
