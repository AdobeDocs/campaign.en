# extAccount

Definition of external accounts (Email, SMS...) used by the modules

## Methods

| Method | Description |
| --- | --- |
| [CreateFDASchema](sm-extaccount-createfdaschema.md) | Creates the working schema in the database |
| [DeclareTableSpaces](sm-extaccount-declaretablespaces.md) | Declares the options, required for using specific tablespaces in the remote database accessible via the external account, in the Adobe Campaign database. |
| [DeploySQLFunctions](sm-extaccount-deploysqlfunctions.md) | Deploys the functions required by Adobe Campaign Federated Data Access on the remote RDBMS server |
| [TestAccount](sm-extaccount-testaccount.md) | Performs a connection test |

## Generic Methods

| Method | Description |
| --- | --- |
| [create](f-create.md) | Creates a new entity corresponding to a given schema. |
| [load](f-load.md) | Loads and returns an entity corresponding to a given schema and key. |
| [save](m-entity-save.md) | Saves an entity in the database. |
