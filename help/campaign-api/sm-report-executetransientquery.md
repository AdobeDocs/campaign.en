# ExecuteTransientQuery

Executes a query and stores the result in a work table

```text
ExecuteTransientQuery ( String name, String label, String sqltable, XML query )
```

## Parameters

**name** Schema name

**label** Schema label

**sqltable** SQL name of the table

**query** Query definition

## Return value(s)

None.

## Features

**Schema:** [xtk:report](s-xtk-report.md)

**Static:**

Yes
