# UpdateTempSchemasFromDatabase

Updates a collection of schemas based on their physical representation in the database.

```text
[ XML result, String warning ] = UpdateTempSchemasFromDatabase ( XML schema )
```

## Parameters

**schema** Schema to regenerate

## Return value(s)

**result** Generated schema

**warning** Warning

## Features

**Schema:** [xtk:builder](s-xtk-builder.md)

**Static:**

Yes
