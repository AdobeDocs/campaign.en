# CleanupDeliveries

Specifies that the mid-sourcing server should delete certain deliveries.

```text
CleanupDeliveries ( String deliveryId )
```

## Parameters

**deliveryId** List of delivery identifiers in the sending database (comma separated)

## Return value(s)

None.

## Features

**Schema:** [nms:delivery](s-nms-delivery.md)

**Static:**

Yes
