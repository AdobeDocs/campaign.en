# toDocument

Returns an XML document from the text content of this buffer.

```text
toDocument ( [codePage ])
```

## Parameters

**codePage** An integer coding the used character page. By default MemoryBuffer.CODEPAGE\_UTF8.

## Return value

A [DOMDocument](c-DOMDocument.md) type object.
