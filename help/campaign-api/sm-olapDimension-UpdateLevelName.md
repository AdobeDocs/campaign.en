# UpdateLevelName

Updates the internal name of a level based on its expression.

```text
XML result = UpdateLevelName ( XML level, XML dimension )
```

## Parameters

**level** Level to modify

**dimension** Parent dimension of the level

## Return value(s)

**result** Modified level

## Features

**Schema:** [xtk:olapDimension](s-xtk-olapDimension.md)

**Static:**

Yes
