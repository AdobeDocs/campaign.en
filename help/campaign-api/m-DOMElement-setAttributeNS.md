# setAttributeNS

Change the value of an attribute or create a new attribute.

```text
setAttributeNS (namespaceURI, qualifiedName, value)
```

## Parameters

**namespaceURI** URI of the attribute namespace.

**qualifiedName** Qualified name of the attribute.

**value** Attribute text value.

## Return value

None.
