# GetQuantiles

```text
XML result = GetQuantiles ( XML binning, XML fact, String expr, String exprType, Number count, Number cubeId )
```

## Parameters

**binning** Existing binning

**fact** Fact description

**expr** Level expression

**exprType** Expression type

**count** Number of values to generate

**cubeId** Cube identifier

## Return value(s)

**result** New binning

## Features

**Schema:** [xtk:olapCube](s-xtk-olapCube.md)

**Static:**

Yes
