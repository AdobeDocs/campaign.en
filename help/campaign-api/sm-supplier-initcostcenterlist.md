# initCostCenterList

```text
XML resBudgetParameters = initCostCenterList ( Number supplierId, Number messageType, XML budgetParameters )
```

## Parameters

**supplierId** Service provider ID

**messageType** Channel

**budgetParameters** 'budgetParameters' item

## Return value(s)

**resBudgetParameters** Returns the lists of cost categories of the service provider
