# LoadChildrenWithPath

Load the list of children for a given node

```text
XML result = LoadChildrenWithPath ( String parentKey, String folderFilter, Boolean writeAccess, String fullName, String path, Boolean sort )
```

## Parameters

**parentKey** Parent key

**folderFilter** Filter on folders

**writeAccess** The folder returned must be writable

**fullName** Full name of selected node

**path** Full name of selected node

**sort** Sort by alphabetical order

## Return value(s)

**result** Result document

## Features

**Schema:** [xtk:folder](s-xtk-folder.md)

**Static:**

Yes
