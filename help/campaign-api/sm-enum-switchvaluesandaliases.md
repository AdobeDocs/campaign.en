# SwitchValuesAndAliases

Convert a value into an alias and vice versa.

```text
SwitchValuesAndAliases ( XML enums, String mode )
```

## Parameters

**enums** Collection of the enumerations to be converted.

**mode** Conversion mode: must be 'ValuesToAliases' or 'AliasesToValues'.

## Return value(s)

None.

## Features

**Schema:** [xtk:enum](s-xtk-enum.md)

**Static:**

Yes
