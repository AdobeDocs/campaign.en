# BuildForward

Builds the HTML page.

```text
[ String content, Number responseCode ] = BuildForward ( String crypted, XML parameters )
```

## Parameters

**crypted** Reversible crypt for message and delivery part identifiers

**parameters** URL parameters

## Return value(s)

**content** Page content

**responseCode** HTTP response in case of error

**Schema:** [nms:delivery](s-nms-delivery.md)

Yes
