# Deploy

Deployment of categories to an environment.

```text
Deploy ( XML offerCategoryFilter, Number offerEnv )
```

## Parameters

**offerCategoryFilter** Filtering condition defining the categories to copy

**offerEnv** Identifier of the destination environment

## Return value(s)

None.

## Features

**Schema:** [nms:offerCategory](s-nms-offercategory.md)

**Static:**

Yes
