# DOMAttr (Class)

An attribute type node.

## Properties

| Property | Description |
| --- | --- |
| [isId](p-DOMAttr-isId.md) | true if the attribute is an ID type. |
| [name](p-DOMAttr-name.md) | Attribute name. |
| [ownerElement](p-DOMAttr-ownerElement.md) | The element with this attribute or null. |
| [specified](p-DOMAttr-specified.md) | true if the value is explicitely specified (this is not a implicit value by default). |
| [value](p-DOMAttr-value.md) | Attribute text value. |
