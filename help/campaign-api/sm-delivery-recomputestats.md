# RecomputeStats

Recompute delivery and tracking statistics for a delivery action.

```text
RecomputeStats ( Number deliveryId, Number dirtyFlags )
```

## Parameters

**deliveryId** Delivery identifier

**dirtyFlags** Bit field describing what to recompute (see the 'nms:delivery:dirtyFlags' enumeration).

## Return value(s)

None.

## Features

**Schema:** [nms:delivery](s-nms-delivery.md)

**Static:**

Yes
