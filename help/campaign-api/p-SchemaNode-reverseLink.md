# reverseLink

If the element is a link, returns a [SchemaNode](c-SchemaNode.md) object which represents a reverse link (via the target schema). If not, the property is not defined.

```text
reverseLink
```

## Features

**Property of class:** [SchemaNode](c-SchemaNode.md)

**Read only:**

Yes

**Available in:**

* Content management
* Delivery properties
* Typology rule
* JSSP
* SOAP Method
* WebApp
* Workflow
