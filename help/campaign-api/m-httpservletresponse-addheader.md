# addHeader

Adds an additional HTTP header to the response.

```text
addHeader (nom, valeur)
```

## Parameters

**nom** Name of the header to add.

**valeur** Value of the added header.

## Return value

None.

## Features

**Method of class:** [HttpServletResponse](c-httpservletresponse.md)

**Available in:**

* JSSP
* WebApp
