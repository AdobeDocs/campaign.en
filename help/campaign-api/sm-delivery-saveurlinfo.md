# SaveUrlInfo

Save URLs of this delivery as URL templates.

```text
SaveUrlInfo ( XML insUrlList, XML updUrlList )
```

## Parameters

**insUrlList** List of new URLs (not associated with an URL template)

**updUrlList** List of URL templates to update

## Return value(s)

None.

## Features

**Schema:** [nms:delivery](s-nms-delivery.md)

**Static:**

Yes
