# save

> Warning:
>
> Access via file APIs is limited to the **var**, **sftp** and temporary folders of Adobe Campaign.

Saves the content of the buffer to a file.

```text
save (filename)
```

## Parameters

**filename** The name of the file to save.

## Return value

None.
