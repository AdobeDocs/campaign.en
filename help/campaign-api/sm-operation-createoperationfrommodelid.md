# CreateOperationFromModelId

Create a campaign from a campaign template.

```text
Number operationId = CreateOperationFromModelId ( Number modelId, XML operationPlanning )
```

## Parameters

**modelId** Identifier of campaign template

**operationPlanning** Campaign schedule

## Return value(s)

**operationId** Identifier of the instance created

## Features

**Schema:** [nms:operation](s-nms-operation.md)

**Static:**

Yes
