# asset

Marketing resource

## Methods

| Method | Description |
| --- | --- |
| [Cancel](sm-asset-Cancel.md) | Cancel the resource. |
| [CheckValidationAccess](sm-asset-CheckValidationAccess.md) | Verifies whether the current operator is able to review the resource. |
| [Lock](sm-asset-Lock.md) | Locks the resource for the current user in order to inform other users that the resource is being modified |
| [Publication](sm-asset-Publication.md) | Publish the resource. |
| [StartValidation](sm-asset-StartValidation.md) | Submit the resource for approval. |
| [Unlock](sm-asset-Unlock.md) | Frees the resource so that other users can make changes to it |
| [Validation](sm-asset-Validation.md) | Approve a resource. |

## Generic Methods

| Method | Description |
| --- | --- |
| [create](f-create.md) | Creates a new entity corresponding to a given schema. |
| [load](f-load.md) | Loads and returns an entity corresponding to a given schema and key. |
| [save](m-Entity-save.md) | Saves an entity in the database. |
