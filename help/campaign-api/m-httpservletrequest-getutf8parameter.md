# getUTF8Parameter

Returns the value (coded in UTF-8) of a parameter of the query.

```text
getUTF8Parameter (name)
```

## Parameters

**name** Parameter name.

## Return value

The value of the requested parameter.

## Features

**Method of class:** [HttpServletRequest](c-httpservletrequest.md)

**Available in:**

* JSSP
* WebApp
