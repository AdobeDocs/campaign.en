# GenerateForm

Generates the form in Mail or Web mode

```text
String result = GenerateForm ( String formName, Boolean mailMode )
```

## Parameters

**formName** Form name

**mailMode** Generate a form of type Mail

## Return value(s)

**result** Result of the application of the XSL on the form

## Features

**Schema:** [nms:webForm](s-nms-webForm.md)

**Static:**

Yes
