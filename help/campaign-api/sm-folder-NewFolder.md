# NewFolder

Create a folder

```text
XML result = NewFolder ( String parentKey, String schema, String entity, String model, String label, String img )
```

## Parameters

**parentKey** Parent key

**schema** Schema

**entity** Entity

**model** Template

**label** Template label

**img** Image key

## Return value(s)

**result** Result document

## Features

**Schema:** [xtk:folder](s-xtk-folder.md)

**Static:**

Yes
