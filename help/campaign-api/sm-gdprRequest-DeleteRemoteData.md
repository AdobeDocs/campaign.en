# DeleteRemoteData

Delete data on remote instances (mid and execution)

```text
DeleteRemoteData ( String address, Boolean midInstance )
```

## Parameters

**address** Email address or phone number

**midInstance** Request on Mid or Execution instances

## Return value(s)

None.
