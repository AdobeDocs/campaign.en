# RegisterTransientSchema

Saves a schema associated with the results of a query

```text
RegisterTransientSchema ( String name, String label, String sqltable, XML query )
```

## Parameters

**name** Schema name

**label** Schema label

**sqltable** SQL name of the table

**query** Query definition

## Return value(s)

None.

## Features

**Schema:** [xtk:report](s-xtk-report.md)

**Static:**

Yes
