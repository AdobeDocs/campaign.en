# Enumeration (Class)

Represents the definition of an enumeration.

## Properties

| Property | Description |
| --- | --- |
| [baseType](p-enumeration-basetype.md) | Returns a string of characters which provides the enumeration type. |
| [default](p-enumeration-default.md) | Returns a string of characters which provides the default value of the enumeration. |
| [description](p-enumeration-description.md) | Returns a character string that provides a description of the enumeration. |
| [hasImage](p-enumeration-hasimage.md) | Returns a boolean which indicates whether or not the enumeration has an image. |
| [label](p-enumeration-label.md) | Returns a character string that provides the label of the enumeration. |
| [name](p-enumeration-name.md) | Returns a string of characters which provides the name of the enumeration. |
| [values](p-enumeration-values.md) | Returns an object for which each property is an  [EnumerationValue](c-enumerationvalue.md)  object indexed by its value. |
