# GetNewIdsEx

Get a list of unique identifiers from the database, given a sequence name.

```text
String idList = GetNewIdsEx ( Number count, String sequence )
```

## Parameters

**count** Number of identifiers that this method should return

**sequence** Name of the sequence to increment

## Return value(s)

**idList** Comma separated list of identifiers

## Features

**Schema:** [xtk:session](s-xtk-session.md)

**Static:**

Yes
