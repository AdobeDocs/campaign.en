# EvaluateJavaScript

Evaluation of JavaScript code.

```text
XML context = EvaluateJavaScript ( String name, String script, XML context )
```

## Parameters

**name** Script name.

**script** Script code to execute.

**context** Execution context of the test.

## Return value(s)

**context** Execution context of the test.
