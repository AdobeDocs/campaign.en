# BuildSqlSchema

Generates the code of a schema from the physical structure of the table given in the parameters.

```text
XML schema = BuildSqlSchema ( String dataSource, String tableName )
```

## Parameters

**dataSource** ID of the data source

**tableName** Table name

## Return value(s)

**schema** Generated schema

## Features

**Schema:** [xtk:sqlSchema](s-xtk-sqlSchema.md)

**Static:**

Yes
