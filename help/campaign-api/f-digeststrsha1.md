# digestStrSha1

> Warning:
>
> This function must not be used to create hash based on Personal Information.

Calculates the SHA-1 hash of a string of characters. The string is automatically encoded in UTF-8 before the calculation.

```text
digestStrSha1 (string)
```

## Parameters

**string** The string in which the hash is to be calculated.

## Return value

The SHA-1 hash of the string passed as a parameter.
