# FormatDataPolicy

Applies a transformation to the character string according to the data policy passed as a parameter. Leaves the string unchanged in case of failure.

```text
String result = FormatDataPolicy ( String dataPolicy, String value )
```

## Parameters

**dataPolicy**

**value**

## Return value(s)

**result**
