# GetEntityIfMoreRecent

Load an entity if its MD5 key is different than the one given as a parameter

```text
XML doc = GetEntityIfMoreRecent ( String pk, String md5, Boolean mustExist )
```

## Parameters

**pk** Primary key

**md5** MD5 key

**mustExist**

## Return value(s)

**doc** Result
