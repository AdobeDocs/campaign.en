# GetSourceAsHtml

Form-management source code in HTML format.

```text
[ String source, XML logs ] = GetSourceAsHtml ( XML form, String renderer )
```

## Parameters

**form** Report definition.

**renderer** Document type to generate.

## Return value(s)

**source** Source code.

**logs** Generation logs.

## Features

**Schema:** [xtk:abstractForm](s-xtk-abstractform.md)

**Static:**

Yes
