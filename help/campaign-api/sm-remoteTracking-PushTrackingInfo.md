# PushTrackingInfo

Allows to upload on remote tracking server all information regarding a delivery.

```text
PushTrackingInfo ( String instance, String dbId, String jobId, XML document )
```

## Parameters

**instance** Instance name

**dbId** Database identifier for customer performing a delivery

**jobId** Delivery ID.

**document** Document containing the tracking information for this delivery

## Return value(s)

None.

## Features

**Schema:** [nms:remoteTracking](s-nms-remoteTracking.md)

**Static:**

Yes
