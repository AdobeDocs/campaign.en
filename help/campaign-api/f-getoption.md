# getOption

Returns the value of an option in the options table.

```text
getOption (name [, useCache ])
```

## Parameters

**name** Name of the option.

**useCache** Use the option value cache (by default, it is not used).

## Return value

The value of the option if the option exists, otherwise undefined. The type of the value depends on the type of the option.

## Features

**Available in:**

* Content management
* Delivery properties
* Typology rule
* JSSP
* SOAP Method
* WebApp
* Workflow
