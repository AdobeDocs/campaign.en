# DeleteCollection

Delete a list of entities based on a condition

```text
DeleteCollection ( String schema, XML where, Boolean ignoreDeleteStatus )
```

## Parameters

**schema** Entity schema

**where** Delete condition

**ignoreDeleteStatus** Ignore deleteStatus

## Return value(s)

None.

## Features

**Schema:** [xtk:session](s-xtk-session.md)

**Static:**

Yes
