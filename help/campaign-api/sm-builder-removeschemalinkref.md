# RemoveSchemaLinkRef

Removes the schema and reverse links referencing it.

```text
RemoveSchemaLinkRef ( String id, String extendedSchema )
```

## Parameters

**id** Schema identifier

**extendedSchema** Extension schema

## Return value(s)

None.

## Features

**Schema:** [xtk:builder](s-xtk-builder.md)

**Static:**

Yes
