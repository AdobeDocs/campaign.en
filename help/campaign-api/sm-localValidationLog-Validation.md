# Validation

Approve local target.

```text
Validation ( Number localValidationTaskId, Number localDistributionValId, Boolean refused, String comment )
```

## Parameters

**localValidationTaskId** Approval task identifier

**localDistributionValId** Distribution value identifier

**refused** Reject

**comment** Comment

## Return value(s)

None.
