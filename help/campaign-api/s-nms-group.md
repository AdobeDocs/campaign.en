# group

List of recipients

## Methods

| Method | Description |
| --- | --- |
| [BuildFromCube](sm-group-BuildFromCube.md) | Builds the list based on a selection of cells from a cube. |
| [Cleanup](sm-group-Cleanup.md) | Purges the import journal |
| [ImportFile](sm-group-ImportFile.md) | Starts importing the list. |
| [Register](sm-group-Register.md) | Add one or more records to the list |
| [Unregister](sm-group-Unregister.md) | Delete selected records from the list |
| [createAudienceMapping](sm-group-createAudienceMapping.md) | Create a mapping ID to synchronize a segment |
| [deleteAudienceMapping](sm-group-deleteAudienceMapping.md) | Delete a mapping ID to desynchronize a segment |
