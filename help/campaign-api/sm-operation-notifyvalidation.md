# NotifyValidation

Approval notification in a campaign.

```text
NotifyValidation ( Number deliveryId, Boolean target, Boolean content, Boolean budget, Boolean extraction, Boolean FCP, Boolean sandbox, Boolean edition, Boolean external )
```

## Parameters

**deliveryId** Delivery identifier

**target** Targeting validation

**content** Content approval

**budget** Budget approval

**extraction** Approval of extraction file

**FCP** Proof approval

**sandbox** Target estimation approval

**edition** Content editing

**external** External content approval

## Return value(s)

None.
