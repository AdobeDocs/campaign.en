# TransformFromId

Publishing transformation from a content Id

```text
[ String format, String result ] = TransformFromId ( String publishingId, String modelName, String contentId )
```

## Parameters

**publishingId** Identifier of publication template

**modelName** Name of transformation template

**contentId** Content identifier

## Return value(s)

**format** Output format

**result** Transformation result

## Features

**Schema:** [ncm:publishing](s-ncm-publishing.md)

**Static:**

Yes
