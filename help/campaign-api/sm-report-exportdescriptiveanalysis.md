# ExportDescriptiveAnalysis

Export descriptive analysis in progress

```text
String fileName = ExportDescriptiveAnalysis ( XML entity, XML execContext, String exportFormat )
```

## Parameters

**entity** Definition of the descriptive analysis

**execContext** Execution context.

**exportFormat** Export format

## Return value(s)

**fileName** Export format

## Features

**Schema:** [xtk:report](s-xtk-report.md)

**Static:**

Yes
