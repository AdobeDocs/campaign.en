# BuildTableList

Gets a list of table names.

```text
XML tableList = BuildTableList ( String dataSource, String tablePattern )
```

## Parameters

**dataSource** ID of the data source

**tablePattern** Mask for the table name

## Return value(s)

**tableList** lists of existing tables

## Features

**Schema:** [xtk:sqlSchema](s-xtk-sqlSchema.md)

Yes
