# GenerateAnalysisWidget

Generate the widget for display.

```text
XML javascript = GenerateAnalysisWidget ( XML entity, String javascriptId, XML queryResult )
```

## Parameters

**entity** XML document describing the widget

**javascriptId** Unique ID of the widget

**queryResult** XML document containing the data

## Return value(s)

**javascript** Widget creation JavaScript

## Features

**Schema:** [xtk:report](s-xtk-report.md)

**Static:**

Yes
