# Generate

Generate the package

```text
specFile.Generate () const
```

## Parameters

None.

## Return value(s)

None.

## Remarks

The package is stored on the server and can be accessed via the URL: /nl/jsp/downloadFile.jsp?md5=package\_&lt;ns&gt;\_&lt;name&gt;&amp;ext=xml Where ns is the namespace of the package definition, and name its name.
