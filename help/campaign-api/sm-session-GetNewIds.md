# GetNewIds

Gathers a list of internal keys identifiers for the database.

```text
String idList = GetNewIds ( Number count )
```

## Parameters

**count** Number of identifiers that this method should return

## Return value(s)

**idList** Comma separated list of identifiers

## Features

**Schema:** [xtk:session](s-xtk-session.md)

**Static:**

Yes
