# GetInputValues

Searches the possible values for an input zone in a form.

```text
XML options = GetInputValues ( String schema, XML input )
```

## Parameters

**schema** Survey edit schema.

**input** Input zone.

## Return value(s)

**options** Possible values for this input zone.

## Features

**Schema:** [xtk:abstractForm](s-xtk-abstractform.md)

**Static:**

Yes
