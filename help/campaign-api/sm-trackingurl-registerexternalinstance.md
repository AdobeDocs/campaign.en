# RegisterExternalInstance

Approves a tracking instance on a relay server for the redirection servers (by setting the database identifier).

```text
RegisterExternalInstance ( String login, String instanceName, String dbId, Boolean saveParams )
```

## Parameters

**login** Relay server access login

**instanceName** Name of the instance to approve

**dbId** Database identifier for customer performing a delivery

**saveParams** Save options if successful

## Return value(s)

None.

## Features

**Schema:** [nms:trackingUrl](s-nms-trackingurl.md)

**Static:**

Yes
