# publishing

Templates used for content publication

## Methods

| Method | Description |
| --- | --- |
| [CheckJavaScript](sm-publishing-checkjavascript.md) | Check the validity of a JavaScript transformation |
| [CheckXSLT](sm-publishing-checkxslt.md) | Check XSLT based transformation |
| [GenerateForDelivery](sm-publishing-generatefordelivery.md) | Generates a content for a delivery |
| [GenerateFromId](sm-publishing-generatefromid.md) | Generates and publishes content referenced by an identifier in a folder |
| [GenerateFromSel](sm-publishing-generatefromsel.md) | Generate an publish a list of contents from a selection |
| [LoadContent](sm-publishing-loadcontent.md) | Load a content from a list of identifiers |
| [Transform](sm-publishing-transform.md) | Publishing transformation from a content |
| [TransformFromId](sm-publishing-transformfromid.md) | Publishing transformation from a content Id |
| [TransformJavaScript](sm-publishing-transformjavascript.md) | JavaScript based publishing transformation |
| [TransformJavaScriptDOM](sm-publishing-transformjavascriptdom.md) | JavaScript based publishing transformation |
| [TransformXSLT](sm-publishing-transformxslt.md) | XSLT based publishing transformation |
