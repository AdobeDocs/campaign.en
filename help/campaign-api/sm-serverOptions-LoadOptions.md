# LoadOptions

> Warning: This function is available for an on-Premise environment.

Load server options

```text
XML result = LoadOptions ( XML select )
```

## Parameters

**select** Select XPaths of options to load

## Return value(s)

**result** Update options document

## Features

**Schema:** [xtk:serverOptions](s-xtk-serverOptions.md)

**Static:**

Yes
