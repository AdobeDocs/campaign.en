# isSameNode

Tests whether the given reference represents the same node.

```text
isSameNode ()
```

## Parameters

None.

## Return value

true if both references represent the same node, otherwise false.

## Remarks

This method must be used to compare two references, the JavaScript operators == and === cannot be used.
