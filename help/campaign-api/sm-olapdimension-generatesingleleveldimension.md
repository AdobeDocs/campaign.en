# GenerateSingleLevelDimension

Generate a single-level dimension based on a field.

```text
XML result = GenerateSingleLevelDimension ( XML dimension, XML field )
```

## Parameters

**dimension** Dimension to enter

**field** Field or expression used

## Return value(s)

**result** Entered dimension

## Features

**Schema:** [xtk:olapDimension](s-xtk-olapdimension.md)

**Static:**

Yes
