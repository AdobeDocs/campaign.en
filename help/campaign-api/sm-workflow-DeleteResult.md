# DeleteResult

Erases the results of one or more activities.

```text
DeleteResult ( String workflowId, String activityName )
```

## Parameters

**workflowId** Identifier or internal name of the workflow.

**activityName** Name of activity(ies) whose results you want to erase

## Return value(s)

None.

## Features

**Schema:** [xtk:workflow](s-xtk-workflow.md)

**Static:**

Yes
