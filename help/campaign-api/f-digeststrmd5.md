# digestStrMd5

> Warning:
>
> This function must not be used to create hash based on Personal Information.

Calculates the MD5 hash function for a string of characters. The string is automatically coded in UTF-8 before calculation.

```text
digestStrMd5 (string)
```

## Parameters

**string** The string for which the hash funtion is to be calculated.

## Return value

The MD5 hash of the string passed as a parameter.
