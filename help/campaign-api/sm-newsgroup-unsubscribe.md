# Unsubscribe

Unsubscribe an operator from a discussion forum.

```text
Unsubscribe ( Number operatorId, String schema, Number entityId )
```

## Parameters

**operatorId** Operator ID

**schema** Schema of the entity linked to the forum

**entityId** ID of the entity linked to the forum

## Return value(s)

None.

## Features

**Schema:** [nms:newsgroup](s-nms-newsgroup.md)

**Static:**

Yes
