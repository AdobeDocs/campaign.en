# SchemaKey (Class)

Represents the definition of a key.

## Properties

| Property | Description |
| --- | --- |
| [label](p-SchemaKey-label.md) | Returns the short description of the key. |
| [description](p-SchemaKey-description.md) | Returns the description of the key. |
| [name](p-SchemaKey-name.md) | Returns the identifier of the key. |
| [isInternal](p-SchemaKey-isInternal.md) | Returns true if they key is the internal key. |
| [allowEmptyPart](p-SchemaKey-allowEmptyPart.md) | Returns true if fields of the key can be empty (at least one of the fields must be entered). |
| [fields](p-SchemaKey-fields.md) | Returns a table which contains the field of fields (  [SchemaNode](c-SchemaNode.md)  ) of the key. |

## Features

**Available in:**

* Content management
* Delivery properties
* Typology rule
* JSSP
* SOAP Method
* WebApp
* Workflow
